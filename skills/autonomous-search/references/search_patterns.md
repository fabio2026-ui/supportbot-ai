# 搜索模式参考指南

## 📋 概述
本文档提供了各种搜索场景下的最佳实践和模式参考，帮助优化搜索查询，提高信息检索效率。

## 🔍 通用搜索模式

### 1. 技术问题搜索
```
基础模式: [技术] + [问题] + [环境/版本]
优化模式: [技术] [问题] [环境] [错误代码] [年份]

示例:
- 基础: "Python安装失败"
- 优化: "Python 3.11 installation failed Windows 11 error code 0x80070005 2026"
```

### 2. 最佳实践搜索
```
基础模式: [技术] + "最佳实践"
优化模式: [技术] best practices [具体场景] [年份]

示例:
- 基础: "Docker最佳实践"
- 优化: "Docker best practices production security 2026"
```

### 3. 教程/指南搜索
```
基础模式: [主题] + "教程"
优化模式: [主题] tutorial [难度] [工具] [年份]

示例:
- 基础: "React教程"
- 优化: "React tutorial beginner TypeScript Vite 2026"
```

### 4. 错误解决搜索
```
基础模式: [错误信息]
优化模式: [技术] [错误关键词] [操作系统] [版本] [解决方案]

示例:
- 基础: "ModuleNotFoundError"
- 优化: "Python ModuleNotFoundError Windows 11 pip install fix"
```

## 📊 搜索效果评估指标

### 1. 相关性评分
```
- 高相关性: 搜索结果直接回答查询
- 中相关性: 搜索结果部分相关
- 低相关性: 搜索结果不相关
```

### 2. 时效性评分
```
- 最新: 1年内
- 较新: 1-3年
- 较旧: 3年以上
```

### 3. 权威性评分
```
- 高权威: 官方文档、知名机构
- 中权威: 技术博客、社区文章
- 低权威: 个人博客、未经验证信息
```
